Spec compliance
---------------

PASS.

`main()` now maps CLI arguments to the `collect()` signature explicitly:

- `--corpus` -> `collect(corpus=...)`
- `--preregistration` -> `collect(preregistration_path=...)`
- `--source-root` -> `collect(source_root=...)`
- `--raw-root` -> `collect(raw_root=...)`
- `--codex` -> `collect(codex=...)`

This fixes the previous mismatch where `vars(arguments)` supplied `preregistration` but `collect()` requires `preregistration_path`.

Regression test validity
------------------------

PASS.

`test_cli_main_maps_preregistration_option_to_collect_parameter` patches `sys.argv`, patches `api_runner.collect`, calls `api_runner.main()`, and asserts the exact keyword arguments passed to `collect()`. This test directly fails against the old `collect(**vars(arguments))` implementation and passes against the explicit mapping.

Executor hash and preregistration binding
-----------------------------------------

PASS.

The recorded executor hash in `examples/effect-experiment-native-v6/preregistration.json` matches the current bytes of `scripts/run_native_cleanup_effect_v6_api.py`.

The preregistration is also internally bound:

- `protocol_sha256` matches the canonical SHA-256 of `protocol`.
- `envelope_sha256` matches the canonical SHA-256 of the immutable envelope.
- `create(ROOT)` reconstructs the committed preregistration exactly.

API-key and auth-output handling
--------------------------------

PASS.

Within the scoped entrypoint:

- API-key login status is checked in memory via `auth_text`, but no auth output artifact is written.
- Agent stdout/stderr is persisted only through `transcript_text(...)`, which applies `redact(...)`.
- No literal API key was found in the scoped files.
